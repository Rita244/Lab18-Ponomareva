## Контрольные вопросы

1. Заменять пару чисел (a, b) на (b, a % b), пока остаток не станет нулём — тогда ответ равен оставшемуся числу

2. Евклид сразу уменьшает задачу за несколько шагов, а перебор делителей проверял бы почти всё число

3. Если делитель больше корня, то его «пара» обязательно меньше корня — значит, её мы уже нашли. Проверять выше корня бессмысленно

4. Хранит пары «число → счётчик»: за один проход считаются частоты всех чисел сразу.

5. Одни и те же значения считаются много раз, потому что каждый вызов порождает ещё два, а результаты не запоминаются

6. Один и тот же правильный ответ можно получить с очень разным количеством работы — и небольшое улучшение алгоритма даёт большую экономию

7. Словарь считается один раз, а дальше каждая частота берётся мгновенно по ключу — без нового прохода по массиву
